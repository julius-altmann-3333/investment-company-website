# AURELIS CAPITAL — Bootstrap 5 Luxury Investment Landing Page

Open `index.html` in a browser.

## Included
- Bootstrap 5.3 responsive layout
- Luxury dark/ivory/champagne design system
- Desktop navigation + mobile offcanvas menu
- Independent section IDs and prefixed classes
- Separate standalone JS files
- Clickable investment image gallery
- Horizontal investment opportunity slider
- Video section
- Animated statistics
- Portfolio allocation visualizer
- Compound-growth calculator
- Market dashboard UI
- Responsive contact form validation
- Newsletter interaction
- EN / DE / FR language switch
- Scroll-to-top button
- Scroll reveal animations
- Reduced-motion support
